# Instrucciones para asistentes de desarrollo

Leer `README.md`, `docs/ARCHITECTURE.md`, `docs/CONTRIBUTING.md` y el `experiments/<slug>/README.md` aplicable.

- Trabajar exclusivamente en la carpeta del experimento indicado, salvo ajustes transversales autorizados.
- No crear servicios backend ni dependencias compartidas obligatorias.
- No atribuir privacidad u operación offline a APIs sin verificarlas.
- Aislar dependencias y mantener rutas relativas compatibles con GitHub Pages.
- No publicar material sensible ni hacer afirmaciones de pruebas no realizadas.
- Entregar cambios mediante rama y pull request, con pasos de validación.

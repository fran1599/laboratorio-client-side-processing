¿Con qué tecnologías está construido?

El escenario se precalcula y se reutiliza en cada fotograma. La versión móvil reduce resolución, partículas y efectos; no necesita servidor ni imágenes externas. Se puede abrir directamente como archivo .html o publicar en GitHub Pages.

¿Qué demuestra este prototipo?

Un bucle de juego con movimiento, colisiones, enemigos que persiguen al jugador, proyectiles, partículas, objetos coleccionables, puntos, vida, temporizador y condiciones de victoria y derrota. El botón Gráficos permite comparar la calidad y el contador muestra los cuadros por segundo (FPS). La interfaz funciona con teclado, mouse y pantalla táctil.
